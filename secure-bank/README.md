# SecureBank

Application fictive de services financiers, projet fil rouge de la serie BUILD SECURE.

Elle est construite puis securisee progressivement, semaine apres semaine, en public.

## Fonctionnalites prevues

Inscription, authentification, gestion des utilisateurs, gestion des comptes, transferts, API REST, dashboard, roles et permissions, upload de documents, notifications, base de donnees.

## Etat actuel

Non demarree. Le premier squelette (v0.1) est construit dans la session 1, voir [sessions/semaine-01-pourquoi-appsec](../sessions/semaine-01-pourquoi-appsec).

## Trajectoire

**v0.1 (point de depart)**

- Authentification faible
- Autorisation mal implementee
- API insuffisamment protegee
- Validation des entrees insuffisante
- Gestion des sessions faible
- Plusieurs autres vulnerabilites applicatives, introduites au fil des sessions

**v1.0 (objectif final)**

- Authentification robuste
- Autorisation correcte
- API securisee
- Sessions securisees
- Validation des entrees
- Tests de securite
- CI/CD securisee
- Security by design

## Avertissement

Cette application contient volontairement des vulnerabilites a but pedagogique. Ne jamais la deployer en production ni sur un environnement accessible publiquement. A utiliser uniquement en local ou dans un environnement de lab isole.
